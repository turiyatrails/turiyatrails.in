# turiyatrails.in

The Turiya Trails website. Plain static HTML, generated by a small Python script, so it can be hosted anywhere (Netlify, GitHub Pages) without a build step on the server.

## How it fits together

| Where | What it is |
|---|---|
| `src/data.py` | **All business content**: journeys, prices, itineraries, day sessions, treks, places, team, FAQ, WhatsApp number. Edit this most often. |
| `src/pages.py` | The layout and wording of each page. |
| `src/templates.py` | Shared pieces: `<head>` and SEO tags, navigation, footer, image slots. |
| `src/journal/*.md` | Journal (blog) articles, one Markdown file each. |
| `src/art.py` | The ridge, forest and sky illustrations shown until real photos are added. |
| `assets/css/site.css` | All styling. Colours, fonts and spacing are variables at the top. |
| `assets/js/site.js` | Menu, header, gentle reveals and the WhatsApp enquiry form. |
| `build.py` | Generates every `.html` page, `sitemap.xml` and `robots.txt`. |

The `.html` files in the root, `journeys/` and `journal/` are **generated**. Edit `src/`, then rebuild. Do not edit the generated HTML by hand, because the next build will overwrite it.

## Making a change

```bash
python3 build.py                 # rebuild everything
python3 -m http.server 8000      # preview at http://localhost:8000
```

Needs Python 3.9 or newer and nothing else. Pillow (`pip install pillow`) is optional; with it, photos are also resized and converted to WebP.

### Change a price or itinerary
Edit the journey or session in `src/data.py`, rebuild. The price updates on the homepage, the journeys list, the journey page, the enquiry form and the search-engine data at the same time.

### Add a journal article
Create `src/journal/your-article-slug.md`:

```markdown
---
title: Birdwatching in the Kumaun hills, a beginner's guide
description: One or two sentences for Google, about 150 characters.
standfirst: The italic line under the headline.
date: 2026-11-15
category: Birds
number: 03
---
Your first paragraph...

## A section heading

More text, **bold**, *italic*, [a link](/birdwatching.html), and

> a pull quote on its own line.
```

Add `draft: true` to the front matter to keep an article off the site until it is ready. Rebuild, and the article appears on the journal page, the homepage and in `sitemap.xml`.

### Add photos
Put a photo in `assets/img/photos/` named after the slot it fills, then rebuild. Until a slot has a photo, it shows an illustration. Use landscape photos at least 1800px wide (portrait for journey cards works too; they are cropped to fit).

| Slot name | Where it appears |
|---|---|
| `home-hero` | Homepage, full-screen first image |
| `home-intro` | Homepage, beside "Not another adventure company" |
| `forest-walks`, `birdwatching`, `stargazing`, `treks` | Homepage, "Four ways to walk slowly" |
| `journey-<slug>` | Journey cards and journey page headers, e.g. `journey-first-light.jpg` |
| `trek-<slug>` | Treks page, e.g. `trek-pandavkholi.jpg`, `trek-khalia-top.jpg`, `trek-pindari.jpg` |
| `journeys-hero`, `experiences-hero`, `treks-hero`, `oakakhi-hero`, `about-hero` | Page headers |
| `forest-walks-hero`, `birdwatching-hero`, `stargazing-hero`, `nature-classes-hero` | Experience page headers |
| `oakakhi-house` | Oakakhi page, beside the introduction |

Only use photos you have the right to publish, and preferably your own from real Turiya Trails journeys.

## Publishing

1. Work on a branch, never directly on `main`.
2. Rebuild, preview locally, and commit both `src/` and the generated files.
3. Open a pull request and review it.
4. Merge into `main`. The live site updates from `main`.

To undo a release, revert the merge commit on `main`.

## Settings to confirm

- `SITE["url"]` in `src/data.py` is the canonical address used in search results and the sitemap. It is set to `https://turiyatrails.in` to match the `CNAME` file. If the live site's main address is `https://www.turiyatrails.in`, change it there and rebuild.
- `.nojekyll` tells GitHub Pages to serve the files exactly as they are. It has no effect on Netlify.
